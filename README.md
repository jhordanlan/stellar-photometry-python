# Stellar Photometry with Python

Processing and analysis of astronomical images from the **Danish 1.54-meter Telescope** to perform stellar photometry and determine standard stellar magnitudes.

## Project Overview

This project involved the processing and calibration of astronomical images in FITS format, followed by photometric analysis of selected stars.

The workflow included the organization of observational data, image calibration, photometric measurements, and analysis of the resulting data.

## Data Processing

The analysis included:

- Organization and classification of FITS files according to their type: bias, flat, and science images.
- Bias and flat-field correction of science images.
- Extraction and processing of photometric information.
- Calculation of standard stellar magnitudes using standard aperture photometry.
- Differential photometry for comparative analysis of stellar brightness.

The processed observations were used to obtain calibrated stellar magnitudes and perform photometric analysis using both standard and differential photometry techniques.
